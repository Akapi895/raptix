## Spec

### Reproduced acceptance failures

`src/real/precommit-regressions.test.tsx` contains 13 failing regressions. It mocks
network/EventSource as the environment; production adapters, components and stream
hooks remain the system under test. The tests are intentionally red pending fixes.

1. Run-page validation accepts `runs: [null]` (`api.ts:170-174`).
2. Findings adapter accepts a valid DTO with a foreign engagement ID
   (`api.ts:232-234`). Requested scope must match returned scope, including items.
3. Caller abort during response-body consumption becomes an internal-error
   shape failure (`transport.ts:42-44,119`).
4. Replaying an identical SSE event invokes the delta consumer twice
   (`stream.ts:62-65`). Cursor and dedup event ID are different concepts.
5. A valid-shaped foreign-scope SSE event reaches the consumer.
6. A buffered callback from the old closed source reaches the new-scope callback.
7. Planning handoff is enabled while readiness is blocked
   (`screens/planning-panel.tsx:136-140`).
8. `findings: [], truncated: true` renders an ordinary empty state without an
   incomplete-source warning (`screens/findings-panel.tsx:40-46`).
9. Lost POST acknowledgement yields no Reconcile action and discards the client
   request identity (`screens/workspace.tsx:203-223`). A retry can create a new ID.
10. A mounted busy conversation never queries its owned runs to restore active
    observation (`screens/workspace.tsx:78-105,123-142`).
11. Execution composer is enabled even when `threadVerified: false`.
    Runtime-context query also omits the selected thread ID (`api.ts:202-205`).
12. Runtime `rawStatus: success` leaves Cancel run visible and the observation
    active. The browser expects completed/failed/cancelled, but server terminal
    statuses are success/error/timeout/interrupted
    (`server/src/services/runtime/run-service.ts:14,104`).
13. Two pending interrupts submit only one value/questionId instead of an
    exhaustive answers batch. The real server rejects that shape
    (`server/src/services/runtime/run-service.ts:131-152`).

Additional source-confirmed gaps: thread switches retain `activeRunId`; delayed
ACKs can install a run into a newly selected thread; checkpoint SSE events lose
provenance when rendered as current-run activity; the Refresh view action merely
dismisses the recovery banner; failed create/send/resume mutations have no error
handler to preserve intent. These require focused regressions during repair.
